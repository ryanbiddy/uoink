# AW-9: B4 remains unaccepted

AV-5m4b4 Grok `e2580c74-1d67-43ad-a5d2-f443409a0c6c` finished from
`564836c`. The integrator reproduced its named union: **255 passed, nine
failed**, 134.12 seconds. Those nine are the retained frozen Phase 4
setup/interceptor cases. AW-4 through AW-7 and A3 pass in this union.
This does not establish operation lifetime across caller return.

Three additional observations prevent integration:

1. **Unknown writer is forgotten.** After the launcher exits, a writer whose
   process query returns `unknown` is treated as dead by `physically_alive()`.
   `_kill_vault_io` discards the session. `_pid_is_alive` tests only `alive`;
   lease-query handling of `unknown` does not repair this separate path.
2. **A mutex handle does not retain thread ownership.** A real thread acquires
   `_exclusive`, starts an actual writer, and returns before a lease exists.
   B4 stores the mutex handle on the live session, but Windows abandons mutex
   ownership when that thread exits. A second process acquired the same
   destination mutex while the original writer remained alive. Final probe:
   competitor PID 12276, original writer PID 68796.
3. **Startup failure loses exclusion.** The startup probe launches a real
   child and simulates missing readiness plus unsuccessful termination.
   `start()` raises before `_start_vault_io` stores the session. After the
   caller exits, a competitor acquires the destination mutex while the
   original launcher (PID 53108) remains alive. No lease was written and
   `Mirror._vault_io` did not retain the session. The simulated uncertainty
   is explicit; this is not a claim that Windows termination failed naturally.

The first two diagnostics failed on the draft in **0.96 seconds**. Their
unchanged final-source recheck, separately briefed before execution, produced
**two failed in 1.01 seconds**. The new startup diagnostic produced **one
failed in 3.12 seconds**. Cleanup terminated only the sessions created by
these probes. No production index, service, model or API was used.
