G2 passes. Weighted BM25 put the hand-selected relevant item or channel higher


## Method

I ran `PYTHONPATH=. python scripts/library/bm25_eval.py` against
`uoink-index-copy-2026-09-04.db`, opened with SQLite `mode=ro` and
`PRAGMA query_only=ON`. The copy contained 548 items and 3,216 clips at schema
version 24.

The 20 relevance judgments are stored beside the queries in the harness: seven
queries use words from a known item's title, five use an exact channel name,
and eight use phrases read from a known item's corpus body. For each query, the
harness ranks the full result set twice and prints both top fives side by side.
A channel query counts the first item from that exact channel as relevant; the
other queries use one fixed `video_id`.
