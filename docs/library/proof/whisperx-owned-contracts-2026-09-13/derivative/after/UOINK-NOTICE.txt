The complete upstream BSD 2-Clause software license is preserved in LICENSE.
Changes require an owned runtime, local admitted assets, injected fixed VAD,
validated waveform input and runtime-owned filter banks. Default legacy VAD
loading and automatic file decoding are removed. Alignment, diarization,
Silero Hub and upstream CLI entry points refuse. Dependency declarations bind
the reviewed B3 faster-whisper derivative and proposed candidate versions.

No model, NPZ, storage, wheel or other binary asset is included in this proposal.
The software license is not a license grant for a future model artifact. Any
model or filter distribution needs its own complete provenance, notices,
manifest, owner decision and qualification. This draft is unbuilt, uninstalled
and unqualified; its owned runtime integration port remains absent.
