# Factory transaction integration and limits

The source supplies actual build_strict_owned and release_product methods for the bridge's factory interface. It does not invoke the frozen factory function as an opaque callback: its fixed constructor/load/VAD steps are reproduced directly so the port can hold each returned model/VAD before the next fallible operation. The original factory document remains unchanged. A later reviewed module extraction must bind its helper/classes to the original factory SHA and the captured runtime sources; caller-supplied module names or profiles provide no execution authority.

The reproduced fixed choices are PyanNet at 16,000 Hz, one channel, SincNet stride 10; a monolithic four-layer bidirectional LSTM with 128 hidden units, dropout 0.5, batch_first/bias true and proj_size 0; two 128-unit linear layers; and the original Specifications mapping. min_duration=None and powerset_max_classes=None remain explicit proposed version-bridge choices absent from recorded checkpoint metadata. The three latent speaker-slot class labels create no speaker attribution claim. The VAD keeps five-second windows, 0.5 step, batch 32, the original aggregation/conversion flags and thresholds 0.500/0.363 with 0.1-second minimum on/off durations.

The source adds ownership/validation around those calls:

1. Bind the supplied 54 exact ordinary tensors through the paired owned CPU port. Capture each owner's facts and the digest of bounded little-endian F32 readback. No file, source snapshot or descriptor callback is accepted here.
2. Retain the returned model before assigning Specifications or calling build. Check empty instance state/load-hook dictionaries before state_dict/load operations, with a 256-module bound. This does not certify source-defined methods, global hooks, import behavior or native dispatch.
3. Preserve the original fresh-state schema check, strict=True/assign=False load, requires_grad_(False) and eval. Require current F32/no-swap/no-overwrite settings before loading and after transitions. Environment checks are current values only; an external startup receipt must establish settings before imports.
4. For every final state entry, retain its ordinary native storage, validate the logical range and compare readback to the input digest. Reject overlap between the entire model storage and every live input storage. Model tensors may share their own storage with each other; this preserves the possibility of a native LSTM layout. Recheck all pinned ranges and values while original storages remain held. Confirm input facts and values also stayed unchanged.
5. Retain the returned VAD before instantiate, then repeat final state verification. A completed owner contains the model, VAD and 54 model-state records; it contains no input Tensor/snapshot records. The fixed 54 input records are local and are cleared before return.
6. A failed build retires returned owners and local state-view collections before propagating a bounded phase or exact refusal. A successful product is returned only after bookkeeping and weak-reference setup. The paired bridge can then release temporary inputs; the native trial must confirm the product remains correct after that release.

The factory has its own 30-second cooperative budget, checked between modules, entries, bounded readback chunks and construction stages. The existing bridge separately checks its original deadline after this call. The interface does not pass the bridge's remaining time into the factory, so this internal ceiling is not a claim of a shared preemptive 30-second wall-clock limit. A blocked constructor or native call cannot be interrupted by these checks.

On release, the port retires its record and storage/model references. It deliberately performs no unsupported close call and does not mutate possibly caller-held model parameters. Normal return confirms reference retirement by this port. Caller/bridge references, exception tracebacks, native caches or resources internal to constructors can remain. Constructors that raise before returning must clean their own partial construction; that behavior is an unresolved native prerequisite. A repeated release confirms only prior retirement. No release call establishes OS reclamation, native shutdown completion or that a caller can no longer use the VAD.

The entire proposal assumes exact trusted source/runtime bindings, one private caller and no concurrent mutation. Storage-range checks address parameter/buffer independence, not arbitrary aliases in every reachable Python attribute. Hashing readback is a value consistency check, not checkpoint provenance or model accuracy evidence. Native F32 conversion/view semantics, constructor lifetime behavior, actual import behavior and numerical VAD/ASR compatibility are unmeasured. No fake or native factory test has run.
