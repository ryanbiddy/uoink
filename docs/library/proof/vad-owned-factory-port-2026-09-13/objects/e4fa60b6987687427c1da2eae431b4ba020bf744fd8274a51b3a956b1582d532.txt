# Combined factory/registry inert qualification proposal

Prepare a fixed case set against the exact factory and registry sources. Root reviews the complete harness, source pins and launcher before a single execution. No native import, actual asset, model, source network fetch or product modification is admitted.

Compile the pinned own-source reader, bridge, qualified CPU port, new factory and registry, and the unchanged owned _uoink_owned guard in memory. Use a literal fake Torch/storage implementation extracted from the already qualified CPU-port harness, with generated finite bytes only. A fake PyanNet exposes the exact fixed schema and records constructor/build/load calls; a fake VAD constructor carries the exact preserved owned guard body before its inert parent call. Its guard-body AST must match the preserved derivative source. It must call the real unchanged require_owned_runtime and the concrete new registry, never an always-successful stub.

Parse the frozen fixed-factory text as syntax only, and compile only its two own-source schema helper functions into the inert factory dependency module. Do not execute its import statements, full construction function or any captured Torch source. Compare constructor, Specifications, strict-load, build, requires_grad, eval, VAD and instantiate call literals against the new transaction, allowing only explicit owner/factory qualification and plain_state/state identifier normalization. All capability and ownership additions remain separately reviewed semantics.

Cases will cover successful 54-state construction; passive binding records without the bootstrap permit; foreign/stale factories, registries, generations, models and leases; actual constructor-guard rejection; input/model value and storage substitution; failures in context, constructors, build/load/instantiate and registration; revocation before publication; completed-product lease retention; release/revocation failure and quarantine; no input references in the completed record; and source literal parity. Synthetic revocation must not be reported as native cancellation or quiescence.

Use the same -I -S -B startup discipline, explicit IG_FORBIDDEN_LIVE and scrubbed provider/proxy environment. Preload stdlib, then allow only fixed copied text/control inputs and close reads before own-source compilation. Preserve final metadata/realpath wrapper identities, closed reads, reader REAL_PROFILE=None, absent real-profile enable attributes, owned guard _RUNTIME=None after cases, intact implementation method identities and absence of heavy packages. These controls constrain the exercised Python content/import paths, not the complete OS.

Preserve one fresh labeled attempt with literal ordered membership, bounded JSON, raw stdout/stderr, immediate global native exit, actual outer tool object, source/control before/after hashes and all guard fields. No run or native semantics are claimed by this prepared protocol. Any failure must be preserved and repaired under a new brief/label before another run.

The final prepared set has 59 cases. The first 55-case draft, the documented wrapper/cause expectation correction and three added boundary cases are preserved. Independent review then found and repaired expired weak-reference retirement before any execution; the additional case rejects None after a generated fake product is collected. Factory calls are serialized by contract; only registry generation revocation is modeled at explicit concurrent-operation boundaries. No case qualifies concurrent factory entry or native interruption.
