The original wrapper sets ErrorActionPreference=Stop, invokes native Python and only afterward reads LASTEXITCODE. If its caller supplies PSNativeCommandUseErrorActionPreference=true, a nonzero native exit can throw at invocation and skip the receipt. The repaired copy sets PSNativeCommandUseErrorActionPreference=false before invocation.
