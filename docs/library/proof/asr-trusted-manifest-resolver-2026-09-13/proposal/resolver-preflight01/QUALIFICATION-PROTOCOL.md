Synthetic qualification proposal, 2026-09-13. Do not execute until root independently reviews the resolver, harness and this launch protocol. No product, package, cache, model or network run is included.

The launcher creates a fresh resolver-preflight01 directory, preserves exact resolver/harness/public-plan/brief/protocol/launcher bytes and their before hashes, then invokes the existing native Python with -I -S -B. Before invocation it scrubs provider credential/routing environment variables without printing their values and sets the required IG_FORBIDDEN_LIVE string. This string is asserted by the child; it is never opened. The child asserts isolated/no-site/no-bytecode flags. Launching this one guarded interpreter is the only process action proposed.

The harness preloads only named standard-library modules before installing its audit hook. It reads exactly its three copied input files; it compiles only the copied reviewed resolver source. Subsequent imports are restricted to the preloaded module set. File opens are restricted to those read-only inputs or generated placeholder files below the attempt's synthetic-assets directory. Directory enumeration/creation/removal is restricted to that directory. Links and renames, native APIs, sockets and child processes are refused. Parent ancestor lstat/resolve metadata checks are permitted by the source and are not OS content reads; Python's audit hook does not intercept every stat call. Path-refusal tests trap lstat when testing outside paths. The proof does not claim an OS sandbox or adversarial race containment.

Each filesystem case uses a fresh named fixture directory. It creates at most the selected four/five placeholder files, each under 4 KiB with a fixed synthetic prefix. Fixtures and mutations stay retained after the run. Symlink/reparse/hardlink and identity-race cases use mocked stat metadata on generated files; they create no links and access no external assets. The positive cases cover all six fixed choices and full second bindings. Other cases cover complete accepted manifest schema, trust anchors, fixed revisions, missing hashes, aggregate limits, incomplete/corrupt inventories, ancestor/identity changes, local-only binding and deadlines. The captured public plan is read unchanged and refused as non-manifest data. Its mapped false flags are refused. A separate mapped record keeps all twenty missing hashes while using only synthetic sizes and true flags to verify that flags alone cannot supply missing digests. Neither transformation is an accepted real manifest.

The child returns raw per-case results plus its actual qualification status, startup assertions, input hashes and audit denials. A failed case or denied operation forces exit 1. Startup errors remain raw stderr/native exit with no invented case count. The launcher records the native exit, verifies both originals and copies remain unchanged, preserves raw stdout/stderr and returns the native exit; it must not turn a failed count into success. Any correction requires retained before bytes, a reason and a fresh label. Root may independently repeat only the same reviewed synthetic protocol in its own fresh directory.

Passing these cases would qualify this scratch resolver contract for generated placeholders. It would not enable REAL_APPROVAL, supply the twenty missing SHA-256 values, approve downloads, install packages, prove native loading, authenticate a filesystem writer or prevent replacement after a future constructor opens a path. Production integration still needs a reviewed private asset lifecycle and real manifest decision.
