# Generated operation connection — proposed 2026-09-13

The new module is a drop-in `FLOW` implementation for the generated-only bootstrap. Keep the old `generated_worker_flow.py` loaded under its original name; the new `generated_operation_flow.py` imports it for handle ownership, startup, shutdown and process observation. The existing bootstrap currently loads the old flow as `FLOW`. A later reviewed derivative must add the new module to the fixed source map and bind `FLOW` to it. The child source digest remains the actual derivative bootstrap digest.

The bootstrap and launcher are not adapted or executed in this proposal. Reuse the repaired pipe `73a1109a`, the exact 32-function dispatch map including `SetFilePointerEx`, nine support-file bindings, closed import/read scopes and both-endpoint pending-I/O finalizer. Never substitute the old native04 finalizer. A new source digest and receipt schema are required; old adoption receipts are not generated-operation receipts.

The proposed connection is:

| Call or message | Exact responsibility |
| --- | --- |
| Owned factory starts worker | Original lease permit, process generation, private bootstrap, challenge/ready and inherited-readset adoption remain unchanged. |
| `issue_generated_media_ticket(session)` | Controller issues one private object for the exact owned session. It is never serialized and never resolves a media path. |
| Facade `transcribe(request)` | Calls actual lifecycle admission, contract validation, issued-contract verification and transcription start. No raw model is returned. |
| `begin`, then `next/admit_generated_media` | Child reads the five already-adopted generated files once, validates the complete namespace, then returns a contract bound to generation/manifest/namespace and fixed generated duration/output limits. |
| `next/begin_generated_transcription` | Child checks fixed options and returns a cursor routing ID with zero produced segments. Controller retains a private cursor object. |
| `next/next_generated_segment` | Child returns one indexed fixture-text segment. After two rows it returns EOF. The actual lifecycle validates duration, chronology and aggregate limits before publication. |
| `next/cancel_generated_cursor` | Child retires the active cursor and acknowledges the exact produced count; it cannot return later segments. |
| Empty `cancel` | Child releases its exact adopted set and replies `closed`. Controller still holds parent guards, observes retained process exit and job count zero, then permits parent release. |

Every request/response pair holds a controller operation lock and checks actual live record/worker/permit ownership before and after. The channel supplies ordered authentication; routing IDs are not capabilities. A concurrent session close revokes the lifecycle first, then waits for the serial port call to return. A result that loses the live-state check is refused. The unchanged lifecycle's already-committed passive result publication rule still applies. Any operation exception attempts lifecycle quarantine and preserves the original error. Neither the lock nor a wire acknowledgement proves OS quiescence.

The duration contract is generated: one synthetic second at 16 kHz, two segments, one-word budget with no words returned, and a text limit calculated from the two fixed generated files. This proves no audio decoding, speech recognition, VAD, timestamp accuracy or native model compatibility. Real runtime/profile admission remains absent. Closing before `begin` is implemented as source-only handling for already-adopted, unread handles; the two scenarios below do not measure that branch.

Proposed observations, with separate fresh run directories and exact root admission:

1. `drain`: facade start leaves the produced count at zero; two `next` calls return the two exact generated texts; a third returns EOF. Then actual process exit 0 and empty job precede parent release. Retained facade/stream calls raise `SessionClosed` without another operation exchange.
2. `cancel`: consume the first segment, call the actual stream's `close`, and require the child to acknowledge one produced segment. Another stream read raises `StopIteration` without IPC. Session close still observes actual process exit and empty job; retained references refuse afterward.

For both, retain controller and child raw receipts, actual child/launcher/tool exits, matching action sequences, five exact identities, five inheritance clears, five seek/two-read pairs and 328 generated bytes, parent share-denial and post-release write-open checks, zero pending pipe operations, guards and unchanged sources/controls/support/fixture bytes. Compare actual output rows and counts rather than assuming that a zero exit establishes them. No native measurement has been run for this module.

Production work still needed after this connection: use a reviewed generated bootstrap derivative, connect `_OwnedASRStart` to a worker policy that enforces its selected usage, add a real owned media decoder/ticket issuer, implement durable quarantine and crash recovery, and resolve the reserved runtime/native-loader scope. The generated port's sentinel profile does not accept `_OwnedASRStart` or grant the new adapter model access.
