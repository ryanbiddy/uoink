# Fixed VAD factory against Torch 2.13 source

2026-09-13. Source review only. The reviewed Torch definitions support the proposed 54 state keys and layer shapes. No incompatible constructor or strict-load signature was found in the calls below. This does not qualify the installed package, imports, native state construction, converted tensor values or numerical behavior.

The future launcher needs an explicit pre-import condition: `TORCH_DEVICE_BACKEND_AUTOLOAD=0`. Torch otherwise loads and calls installed `torch.backends` entrypoints. This mechanism also exists in the retained Torch 2.8 source; it is an unresolved import requirement, not a new 2.13 regression. The target additionally imports `torch._native`, whose implementation was outside this 19-file collection. Both limits remain open before a runtime trial.
