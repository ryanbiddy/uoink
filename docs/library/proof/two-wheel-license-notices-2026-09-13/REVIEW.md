# Two wheel notice review, 2026-09-13

Both missing notices are now available as exact upstream text. ANTLR has a version-tagged BSD 3-clause notice. Proxy-tools has a concrete licensing inconsistency: its source header and repository license say BSD, but its packaging metadata says MIT. The proposed release notice preserves the repository text and flags that conflict.

The cached-wheel proof integrated at commit `95a7f29` established that neither wheel contains a license-text member. This review read that retained JSON receipt and public source text; it did not reopen either wheel.

ANTLR's official `4.9.3` tag resolves to commit `e4c1a74c66bd5290364ea2b36c97cd724b247357`, dated 2021-11-06. Its Python setup text declares version 4.9.3. The captured `Recognizer.py` is byte-identical to the corresponding retained wheel member, and its header explicitly points to the root BSD 3-clause license. The entire 2,699-byte root license is retained. Its additional MIT section names two JavaScript files and is not evidence that those files ship in this wheel. [Versioned license](https://github.com/antlr/antlr4/blob/e4c1a74c66bd5290364ea2b36c97cd724b247357/LICENSE.txt), [Python source header](https://github.com/antlr/antlr4/blob/e4c1a74c66bd5290364ea2b36c97cd724b247357/runtime/Python3/src/antlr4/Recognizer.py).

Proxy-tools has no tags in the captured official API response. Commit `f82ae43524fd6d9917b0e9490c7d0394dff8d155`, dated 2014-05-05 20:40:45 UTC, precedes the retained PyPI upload at 21:02:24 UTC. It declares version 0.1.0 and contains the same license and sole package module as current HEAD `db43f1e35d4f90a65c5a4d56d9e9af88212ec6e6`. The complete 6,409-byte module matches the retained wheel-member SHA-256 `d1539d95e1a713c068ca81d42e047b2c76568964cf277596d4e19efb22f476be`. Its header credits extraction from Werkzeug and says BSD. The 1,436-byte license names both Armin Ronacher and Jonathan Tushman and contains two redistribution conditions. The MIT claim also exists in that same historical setup.py; this is an upstream inconsistency, not just a new wheel-generation error. [Historical license](https://github.com/jtushman/proxy_tools/blob/f82ae43524fd6d9917b0e9490c7d0394dff8d155/LICENSE.txt), [source header](https://github.com/jtushman/proxy_tools/blob/f82ae43524fd6d9917b0e9490c7d0394dff8d155/proxy_tools/__init__.py), [conflicting setup](https://github.com/jtushman/proxy_tools/blob/f82ae43524fd6d9917b0e9490c7d0394dff8d155/setup.py).

They do not authenticate a publisher-signed release, establish the exact proxy-tools release commit, or prove that every ANTLR wheel member matches the tag.
