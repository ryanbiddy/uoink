2026-09-13. The state source does not implement Windows protection or process supervision. Its kernel_port is trusted, reviewed bootstrap infrastructure. The default is None and refuses before path or kernel work. Supplying a fake port for these synthetic tests does not enable the unchanged ASR resolver or grant real model approval.

The port must provide these fixed operations. Returned Python objects are local capability references; freely constructed records, path strings, job labels and receipt files are not authority.

| Operation | Required boundary before returning success |
| --- | --- |
| acquire_read(key) | Validate the externally bound canonical root, every ancestor and exact approved snapshot identity. Establish protection against write/delete/reparse changes across all later native path reopens. Refuse an unknown pending/quarantined epoch. Return a retained protection owner only after the boundary exists. |
| start_owned_worker(protection, permit, profile) | Bind a complete approved load/runtime plan to the exact protected snapshot. Reserve recoverable ownership before process creation. Establish the owned process/job and allowed handles before runtime code starts. Return a worker capability for this permit only. |
| quarantine(key, protection, permit, reason) | Revoke further operations, keep protection and worker ownership, and record the unresolved epoch. Return exactly True only after the recovery record is retained by the supervisor. A receipt alone does not protect files or prove termination. |
| close_and_join(worker, permit) | Revoke requests/cursors, stop the owned runtime and wait within the reviewed deadline for all owned processes/threads/native work. Return exactly True only after the owned work is finished. False, None, integer 1, timeout or exception cannot release protection. |
| confirm_quiescent(protection, worker, permit) | Independently bind the termination observation to the same protection, worker creation identity, permit and epoch. Confirm no owned native task can reopen the paths. Process-name lookup or a self-reported child message is insufficient. |
| release_read(protection) | Release the exact retained authority only after state/native quiescence has been confirmed. Any incomplete release is an unresolved quarantine condition. |
| admit_media_request(worker, permit, ticket) | Look up an already-owned, qualified decoder output in the trusted worker-control registry. Derive sample count/rate and output policy from that record; never trust caller or model duration claims. Return a MediaResultContract bound to the same permit. |
| is_issued_media_contract(worker, permit, contract) | Confirm identity against that control registry, including the immutable media region, decoder policy and output limits. Exact dataclass shape by itself must return False. |
| begin_transcription(worker, contract, request) | Resolve only that issued media contract and fixed accepted ASR/VAD plan. Refuse arbitrary filenames, module names, method names and unaccepted options. Create one bounded cursor per session. |
| next_segment(worker, cursor) | Return None or one bounded passive Segment/Word record from the authenticated, length-bounded result channel. Do not deserialize Python/pickle objects or expose model/native generator references. State validates times and aggregate budgets again before delivery. |
| cancel_transcription(worker, cursor) | Confirm cancellation of this exact cursor, including native work already in flight, before returning exactly True. A raised error or other value leaves ownership unconfirmed and is quarantined. |

The current state layer uses one exclusive lease and one transcription per snapshot/session, with serial worker operations. It holds local protection references through native shutdown. Closing revokes all facades and streams before the port runs. A concurrent quarantine cannot be overwritten by a late successful join. An operation already returning passive data is not a raw model reference; a retained facade/stream cannot initiate new native work after revocation.

The media contract is only accepted after the registry check. The proposed source permits at most 24 hours at 16 kHz, 100,000 segments, 1,000,000 words and 8,000,000 combined segment/word text characters, with smaller port-issued limits allowed. Segment and word ranges must stay inside owned media duration and progress without overlap/backtracking. These constraints are unqualified proposal policy. They require product/quality review before any integration; no existing output is sorted, truncated or relabeled to meet them.

Quarantined records have no reset/reuse/delete API in this proposal. The writer entry point always refuses until a real writer protocol exists. In-process references cannot survive process death, and a Python lock cannot exclude other processes. A later kernel implementation and crash-recovery protocol must establish those properties before any real profile can use this state layer.
