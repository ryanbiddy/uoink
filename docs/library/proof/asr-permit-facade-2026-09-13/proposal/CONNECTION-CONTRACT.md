2026-09-13. Proposed interface change; no production integration or execution.

The adapter's public session helpers now yield OperationFacade. They no longer yield a model exposing WhisperX/FasterWhisper constructors or arbitrary model methods. Callers must submit the lifecycle's TranscribeRequest with a worker-issued media ticket and consume its passive SegmentStream inside the context. Holding a facade or stream after exit cannot start further work. Existing proposed call-site splices written for raw model objects must be updated before product integration; this patch does not claim they already work.

The adapter retains the lease's _NativePermit and requires the exact concrete OwnedRuntimeFactory associated with that same lifecycle. It rechecks the local constructor binding before process startup, creates _OwnedASRStart(policy, usage, binding), and calls factory.open_owned_session(startup, permit). That concrete factory verifies the permit and local record before handing the startup data to its kernel port. The returned OwnedSession and OperationFacade must be the exact ones owned by that record. A second lease, serialized token or arbitrary factory cannot replace them.

_OwnedASRStart retains the accepted CPU policy, selected WhisperX/reliability/capture usage and resolver LocalBinding. The binding remains explicitly local-only, constructor_called=False and real_runtime_approved=False. The record grants no model permission. The fixed worker port still must verify the adopted manifest and usage, install its worker-local runtime owner, enforce the relevant VAD contract and construct only within that ownership. No raw native object is placed in this record or returned to the controller. The current generated port does not implement this real ASR startup route; it is not silently treated as a model worker.

The real release/manifest gates remain closed and all service globals remainNone. The profile, consent and acquisition paths still refuse unsupported choices, roots, missing capabilities and non-Boolean consent. Native or inference failures cannot enter the acquisition handler. The exception-aware ExitStack now delivers the original failure to the concrete lease. If session cleanup also fails, that uncertainty is added to the original failure while quarantine remains; if there is no prior failure, cleanup failure is raised. No recovery, writer or release shortcut is added.

The original58 qualification remains evidence for the prior fake factory/model interface. Its source and28 decorated function definitions, which instantiate58 case IDs, are preserved and compared without changing an assertion. It is not a new58-case pass for this different interface. The new six connected cases are unexecuted and have their own IDs. One case checks three usage selections and another checks two early-failure origins; those are checks within six cases, not additional distinct case credit.
