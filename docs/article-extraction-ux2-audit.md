# Article extraction UX2 dependency audit

Decision: Trafilatura was rejected on size and license. It added 46,769,885 bytes (46.77 MB, 44.60 MiB), with CNRI-Python and Unicode data outside the allowlist. The approved replacement is a stdlib Python adaptation of Mozilla Readability with zero new runtime dependencies. The original audit below is retained.

Stopped before implementation on 2026-10-24, as required by the size and license gates. Trafilatura 2.2.0 adds **46,769,885 bytes (46.77 MB, 44.60 MiB)** across 11 new distributions on Windows x64 / CPython 3.11.14. This exceeds the roughly 40 MB limit. The 18-distribution closure occupies 50,231,602 bytes (47.90 MiB), including seven dependencies already in the installer lock.

The closure also fails the stated license allowlist. `regex` declares `Apache-2.0 AND CNRI-Python`; CNRI-Python is outside the list. Its license file confirms that the inherited code retains that license, so choosing Apache alone would not clear it. Although regex is already shipped, it is also required by this proposed closure: Trafilatura -> htmldate -> dateparser -> regex.

Babel includes `babel/locale-data/LICENSE.unicode`, headed `UNICODE LICENSE V3`, in addition to its BSD code license. lxml's wheel `LICENSES.txt` lists zlib under the zlib license and iconv under LGPL-2.1 among its bundled libraries. These are additional exceptions to the stated list. This pass did not establish which native libraries each platform's binary actually links. A distribution's BSD metadata alone does not clear those bundled components.

The handoff's TOP 10 item 2 and verification addendum were read. The elected license for unmodified tld remains MPL-1.1. The findings above come from the installed candidate wheels and go beyond the handoff's tld finding.
