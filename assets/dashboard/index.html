    Browser button

    Get the extension

    The Uoink button lives in a browser extension you load once. It's already on this machine at %LOCALAPPDATA%\Uoink\extension.

    1. Open chrome://extensions in Chrome.
    2. Turn on Developer mode in the top right.
    3. Click Load unpacked and pick the extension folder that just opened.
    4. On a Mac that folder is inside the hidden Library. In the Load unpacked window press ⌘⇧G, paste the path the button copied, press Return, then click Select.
    5. Click the puzzle-piece Extensions icon in the toolbar and pin Uoink, so the Uoink button stays visible.

    Uoink is built and tested for Chrome. Edge and Brave are Chromium-based and may work, but are not tested.

    Chrome Web Store review is still pending, so you load it unpacked for now.

      Taste-aware auto-uoink
      
              
      Off by default. When on, Uoink scores new videos from the playlists you already monitor (above) against your taste — your 10/10 anchors, admired channels, engagement, and corpus — and auto-captures the strong matches. They land in your library labelled auto-uoinked (taste match).
      
              
              
      
              
      Checking auto-uoink status...
      
              
      
                
              
      
              
      Only works over sources you already track — no web crawling, no new accounts. Capture uses the same local download + transcription as a manual save, so there is no AI spend. Reversible: turn it off any time, and auto-captured uoinks are ordinary uoinks you can delete.

      Usage sharing
      
              
              
      
              
      Off by default. If enabled, Uoink sends counts to usage.uoink.app at most once every 24 hours: calls by tool name, known MCP client names, calls over stdio or HTTP, captures by source and result, and library searches. Each report includes a random install ID, a random report ID to prevent repeat counting, Uoink version, operating system and major version, processor type, install type and hours counted. No content, URLs, titles, paths, search text, account details, usernames or IP addresses are included in the report.
      
              
      
              
      Turning this off deletes the random ID, local counts and sent history. Turning it on again creates a new ID.
