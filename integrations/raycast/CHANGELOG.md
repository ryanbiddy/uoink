# Uoink Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Search Library: search saved transcripts, articles and notes; open results at their timestamp; copy or paste Markdown citations; browse recent captures
- Uoink Link and Uoink Current Tab: save links from an argument, the selection, the clipboard or the active browser tab
- Save Note: save text as a searchable note
- Raycast AI tools for search, item details, recent captures, saving links and saving notes, plus `@` mentions of saved items in AI Chat
